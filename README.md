# adb_screenshot

scrcpy の映像ストリームを PC 側で受信し、**受信解像度のまま**スクリーンショットを保存する
ミラーリング／自動キャプチャツールです（Android アプリではなく PC 上で動作します）。

scrcpy 本体にはスクリーンショット機能がなく、デスクトップの表示をキャプチャすると表示解像度に
縮んでしまうため、デコード直後のフレームを直接保存します。

```
scrcpy-server (端末)  --H.264-->  PyAV デコード  --> 最新フレーム (例: 1116x2480)
                                                   ├─ Tk キャンバスへ縮小表示
                                                   └─ 領域を切り出して PNG/JPG 保存
```

## 特徴

- サーバー側で縮小しない（`max_size=0`）。エンコード失敗時の自動縮小も既定で無効
- 受信したセッションヘッダの幅・高さをそのまま使う（端末の回転にも追従）
- 「スクリーンショット → 指定座標をタップ → 画面が静止するまで待つ → …」を指定回数繰り返す
- タップは scrcpy の制御ソケットへ直接注入（`adb shell input tap` も選択可）
- GUI（ミラー表示・領域のドラッグ選択・タップ位置のクリック指定）と `--no-gui` の CLI

## 動作環境

- Linux / Python 3.10 以上
- adb（PATH 上）
- scrcpy 4.x の `scrcpy-server` ファイル
  - 探索順: `--server` > 環境変数 `SCRCPY_SERVER_PATH` > `scrcpy` 実行ファイルと同じディレクトリ > `/usr/share/scrcpy/`
  - バージョン文字列が違う場合はサーバーのエラー出力から検出して 1 回だけ自動で再試行します

```bash
pip install --user -r requirements.txt   # av, numpy, Pillow
```

## 使い方

### GUI

```bash
python3 main.py
```

- **マウス操作モード**
  - 端末を操作: クリック／ドラッグをそのまま端末へ送る
  - 領域をドラッグ選択: 保存する切り出し領域を指定（映像座標で `x,y,w,h` に反映）
  - タップ位置をクリック: 自動実行で使うタップ座標を指定
- **スクリーンショット**: 現在のフレームを受信解像度で保存
- **自動実行 開始**: 回数ぶん「保存 → タップ → 待機」を繰り返す
- 保存ファイル名は `prefix + 0001.png` の連番。既存ファイルの続きから採番します

### CLI（GUI なし）

```bash
# 100 ページ分、(50,1000) をタップしながら 0,84,1200,1836 の領域を保存
python3 main.py --no-gui -n 100 --tap 50,1000 --region 0,84,1200,1836 \
    --interval 1.0 --settle 0.5 -o "週刊少年ジャンプ 2026年40号"
```

主なオプション:

| オプション | 既定 | 説明 |
| --- | --- | --- |
| `-s, --serial` | 自動 | 対象端末（複数接続時は必須） |
| `--bit-rate` | `16M` | 映像ビットレート。文字や線画の細部を重視するなら 16〜24M |
| `--max-size` | `0` | サーバー側の縮小上限（0 = 縮小しない） |
| `--allow-downsize` | off | エンコード失敗時にサーバー側の自動縮小を許可する |
| `--region x,y,w,h` | なし | 切り出し領域（映像座標） |
| `--tap x,y` | なし | 各ショット後にタップする座標（映像座標） |
| `-n, --count` | `1` | ショット回数 |
| `--interval` | `1.0` | タップ後の最小待ち時間 [s] |
| `--settle` | `0.5` | 画面が静止しているとみなす継続時間 [s]（0 で無効） |
| `--timeout` | `10` | 静止待ちの上限 [s]。超えても続行する |
| `--tap-method` | `scrcpy` | `scrcpy`（制御ソケット）/ `adb`（`input tap`） |
| `--display-id` / `--new-display` | なし | 別ディスプレイ／仮想ディスプレイを映す |
| `--format` | `png` | `png` / `jpg` |

## 注意点

- 保存画像は端末側で H.264 圧縮された映像のデコード結果です。`adb screencap` のような無劣化
  PNG ではありません。細部を重視する場合はビットレートを上げてください。
- タップ座標・領域は「受信映像の座標系」です。`max_size=0` なら端末の物理解像度と一致します。
- 起動直後の 1〜2 フレームは真っ黒になることがあるため、最初の保存前に有効なフレームを待ちます。
- サーバーは `/data/local/tmp/scrcpy-server-adbss.jar` に push します（scrcpy 本体とは別名）。

## 構成

```
main.py                      起動スクリプト
adb_screenshot/
  adb.py        adb ラッパー（devices / push / forward / input tap）
  server.py     scrcpy-server の起動・ソケット接続・後始末
  stream.py     映像ストリームの解析、PyAV デコード、最新フレーム保持
  control.py    タッチ／キー注入（scrcpy 4.x ControlMessage 形式）
  capture.py    領域切り出し保存、静止待ち、自動実行ループ
  session.py    上記をまとめたセッション
  cli.py        引数解釈、ヘッドレス実行
  gui.py        Tkinter GUI
```
