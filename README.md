# adb_screenshot

scrcpy の映像ストリームを PC 側で受信し、**受信解像度のまま**スクリーンショットを保存する
ミラーリング／自動キャプチャツールです（Android アプリではなく PC 上で動作します）。

scrcpy 本体にはスクリーンショット機能がなく、デスクトップの表示をキャプチャすると表示解像度に
縮んでしまうため、デコード直後のフレームを直接保存します。

```
scrcpy-server (端末)  --H.264-->  PyAV デコード  --> 最新フレーム (例: 1116x2480)
                                                   ├─ Tk キャンバスへ縮小表示
                                                   └─ 領域を切り出して PNG/JPG 保存
```

## 特徴

- サーバー側で縮小しない（`max_size=0`）。エンコード失敗時の自動縮小も既定で無効
- 受信したセッションヘッダの幅・高さをそのまま使う（端末の回転にも追従）
- 「スクリーンショット → 指定座標をタップ → 画面が静止するまで待つ → …」を指定回数繰り返す
- タップは scrcpy の制御ソケットへ直接注入（`adb shell input tap` も選択可）
- GUI（ミラー表示・領域のドラッグ選択・タップ位置のクリック指定）と `--no-gui` の CLI

## 動作環境

- Linux / Python 3.10 以上
- adb（PATH 上）
- scrcpy 4.x の `scrcpy-server` ファイル
  - 探索順: `--server` > 環境変数 `SCRCPY_SERVER_PATH` > `scrcpy` 実行ファイルと同じディレクトリ > `/usr/share/scrcpy/`
  - バージョン文字列が違う場合はサーバーのエラー出力から検出して 1 回だけ自動で再試行します

```bash
pip install --user -r requirements.txt   # av, numpy, Pillow
```

## 使い方

### GUI

```bash
python3 main.py
```

起動時は未接続です。上部の接続パネルで端末と受信解像度を指定して「接続」します。

- **端末**: `adb devices` の一覧から選ぶか、`IP:port` を直接入力（未接続なら `adb connect` してから開始）
- **受信解像度 幅／高さ**: 片方を入力すると元解像度の縦横比でもう片方を自動計算します。
  指定すると接続時に `wm size` で端末の論理解像度を上書きし、切断時に `wm size reset` で戻します。
  空欄なら端末の解像度のまま受信します
- **切断**: サーバー停止と解像度の復元
- **表示のズーム**: 🔍+ / 🔍− / 全体 ボタン、マウスホイール（カーソル位置基準）。中・右ボタンドラッグ、または「表示を移動」モードで左ドラッグして移動。
  拡大時は最近傍補間なのでピクセル境界が見えます。カーソル位置の映像座標を下部に表示します
- **マウス操作モード**
  - 端末を操作: クリック／ドラッグをそのまま端末へ送る
  - 領域を選択: 枠外からドラッグで新規作成、四隅のハンドルでリサイズ、枠内ドラッグで移動（`x,y,w,h` に反映）
  - タップ位置をクリック: 自動実行で使うタップ座標を指定
  - 表示を移動: 拡大表示中に左ドラッグで表示エリアを移動
- **書籍プリセット**: 書籍名をキーに「保存領域・タップ位置・タップ後待ち・静止判定」を `presets.json` に登録します。
  一覧から選ぶ（または「読込」）と各欄に反映され、「登録/更新」で現在の欄の内容を書籍名で保存、「削除」で除去します
- **書籍名・巻数・号**: 保存先が `保存先ベース/書籍名 巻数/` になります（プレビューを欄の下に表示）。
  巻数が空なら `保存先ベース/書籍名/`、両方空ならベース直下です
- **スクリーンショット**: 現在のフレームを受信解像度で保存
- **自動実行 開始**: 回数ぶん「保存 → タップ → 待機」を繰り返す
- 保存ファイル名は `prefix + 00001.png` の 5 桁連番。既存ファイルの続きから採番します

### CLI（GUI なし）

```bash
# 100 ページ分、(50,1000) をタップしながら 0,84,1116,1836 の領域を
# output/週刊少年ジャンプ 2026年40号/00001.png … に保存
python3 main.py --no-gui -n 100 --tap 50,1000 --region 0,84,1116,1836 \
    --interval 1.0 --settle 0.5 --book "週刊少年ジャンプ" --volume "2026年40号"

# GUI で登録したプリセットを使う（領域・タップ位置・待ち時間を補完、書籍名はプリセット名）
python3 main.py --no-gui -n 100 --preset "週刊少年ジャンプ" --volume "2026年40号"
```

主なオプション:

| オプション | 既定 | 説明 |
| --- | --- | --- |
| `-s, --serial` | 自動 | 対象端末（複数接続時は必須） |
| `--bit-rate` | `16M` | 映像ビットレート。文字や線画の細部を重視するなら 16〜24M |
| `--max-size` | `0` | サーバー側の縮小上限（0 = 縮小しない） |
| `--allow-downsize` | off | エンコード失敗時にサーバー側の自動縮小を許可する |
| `--width` / `--height` | なし | `wm size` で端末の論理解像度を上書き（片方指定で比率維持、終了時に reset） |
| `--region x,y,w,h` | なし | 切り出し領域（映像座標） |
| `--book` / `--volume` | なし | 書籍名・巻数。保存先が `out/書籍名 巻数/` になる |
| `--preset NAME` | なし | `presets.json` のプリセットで未指定の領域・タップ・待ち時間・書籍名を補う |
| `--presets FILE` | `presets.json` | プリセットファイルの場所 |
| `--digits` | `5` | 連番の桁数 |
| `--tap x,y` | なし | 各ショット後にタップする座標（映像座標） |
| `-n, --count` | `1` | ショット回数 |
| `--interval` | `1.0` | タップ後の最小待ち時間 [s] |
| `--settle` | `0.5` | 画面が静止しているとみなす継続時間 [s]（0 で無効） |
| `--timeout` | `10` | 静止待ちの上限 [s]。超えても続行する |
| `--tap-method` | `scrcpy` | `scrcpy`（制御ソケット）/ `adb`（`input tap`） |
| `--display-id` / `--new-display` | なし | 別ディスプレイ／仮想ディスプレイを映す |
| `--format` | `png` | `png` / `jpg` |
| `--quality` | `75` | JPEG 品質 1〜95（`jpg` のみ）。`adb screencap` 系ツールの既定と同程度のサイズになる |

## 注意点

- 保存画像は端末側で H.264 圧縮された映像のデコード結果です。`adb screencap` のような無劣化
  PNG ではありません。細部を重視する場合はビットレートを上げてください。
- タップ座標・領域は「受信映像の座標系」です。`max_size=0` なら端末の論理解像度（`--width/--height` 指定時はその値）と一致します。
- `wm size` による解像度上書きは端末の実画面にも影響します。元画像の情報量が増えるわけではなく、
  アプリがより大きな画面向けに高解像度で描画する場合にだけ効果があります。異常終了で戻らなかった場合は
  `adb shell wm size reset` で復元できます。
- 起動直後の 1〜2 フレームは真っ黒になることがあるため、最初の保存前に有効なフレームを待ちます。
- サーバーは `/data/local/tmp/scrcpy-server-adbss.jar` に push します（scrcpy 本体とは別名）。

## 構成

```
main.py                      起動スクリプト
adb_screenshot/
  adb.py        adb ラッパー（devices / push / forward / input tap）
  server.py     scrcpy-server の起動・ソケット接続・後始末
  stream.py     映像ストリームの解析、PyAV デコード、最新フレーム保持
  control.py    タッチ／キー注入（scrcpy 4.x ControlMessage 形式）
  capture.py    領域切り出し保存、静止待ち、自動実行ループ、保存先ディレクトリの決定
  presets.py    書籍プリセット（presets.json）の読み書き
  session.py    上記をまとめたセッション
  cli.py        引数解釈、ヘッドレス実行
  gui.py        Tkinter GUI
```
